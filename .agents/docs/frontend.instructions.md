# Accessibility and security

- Pass Axe checks and meet Web Content Accessibility Guidelines (WCAG) 2.2 AAA
- Prefer semantic HTML; render dates with `<time datetime>` values generated by `Temporal`
- Do not load cross-origin resources in production
- Do not use `unsafe-inline`; use external styles and scripts
- Change Content Security Policy only in `apps/backend/src/utils/helmet_config.ts`
- When adopting a browser API, update `apps/backend/src/utils/middlewares/permissions_policy.ts`

Development may allow origins required by Vite, Swagger, and GraphiQL.

## React and TSX

- Use function components and hooks
- Define props with interfaces and `readonly` properties where possible
- Accept a `props` parameter; do not destructure props in the function signature
- Do not use the deprecated `React.FormEvent`

## GraphQL

- Store operations in their matching `queries`, `mutations`, or `subscriptions` directory under `apps/frontend/src/api/graphql/`
- After changing the schema or an operation, run `pnpm --filter @oktomusic/frontend codegen`
- Parse ISO date strings through Apollo policies in `apps/frontend/src/api/graphql/client.ts`; generated `Date` types do not parse runtime values
- Do not pass a value already typed as `Date` to `new Date()`

## Images

- Set `fetchPriority` and `loading` on every image
- Optimize SVG files with default SVGO settings
- Optimize PNG files with `oxipng --opt max --strip all --zopfli`

## Icons

Use `react-icons`, preferring the `Lu` Lucide set.

## Forms

Use form controls from `apps/frontend/src/components/Base`. If none fits, use an accessible `@headlessui/react` component.

## Authentication

Read `authSessionAtom` from `apps/frontend/src/atoms/auth/atoms.ts` with Jotai's `useAtomValue`.

Outside authentication flows, protected components may assume an authenticated user and access `authSession.user!`; do not duplicate route-level authentication checks.

## Drag and drop

Use `@dnd-kit` with the global `DragDropProvider` in `apps/frontend/src/App.tsx`. Read `apps/frontend/src/components/TrackList/DND_IMPLEMENTATION.md` before changing track-list drag and drop. Use Context7 library `dndkit` for API documentation.
